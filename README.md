# Lehigh Property Management & Realty

Website for **Lehigh Property Management & Realty** (Elie Daher) — a professional property-management site with home and rentals pages. Built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:4327](http://127.0.0.1:4327).

## Pages

| Route | Purpose |
| --- | --- |
| `/` | Home: announcement + click-to-call, hero, action cards, about, services grid, areas, contact footer |
| `/rentals` | Available rentals with filters and empty state |
